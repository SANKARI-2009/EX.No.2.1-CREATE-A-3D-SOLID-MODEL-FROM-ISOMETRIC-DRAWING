# EX.No.2.1  CREATE A 3D SOLID MODEL FROM ISOMETRIC DRAWING
## Date:

## AIM
To create a 3Dmodel from the given isometric drawing using fusion 360 tool. 

## REQUIREMENTS
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE
STEP 1: Start the Sketch Command 
       Open Autodesk Fusion 360 and select the Design workspace. Click on Create Sketch 
from the Solid toolbar to start a new sketch. The three reference planes (XY, XZ and 
YZ) will appear on the screen. 

STEP 2: Select the Sketch Plane 
        Select the Front (XZ) Plane from the available reference planes. The sketching 
workspace will open, showing the origin and coordinate axes. Make sure that the 
correct plane is selected before starting the sketch. 
 
STEP 3: Create a Rectangle 
      Select Sketch → Rectangle → Center Rectangle. Move the cursor to the origin point 
and click to set the centre of the rectangle. Move the cursor outward and enter the width 
as 100 mm and height as 60 mm using the Tab key. Press Enter to confirm the 
dimensions and complete the rectangle. After checking the dimensions, click Finish 
Sketch.

STEP 4: Extrude the Rectangle 
         Select Solid → Create → Extrude and click on the rectangular profile. Enter the 
extrusion distance as 30 mm in the dialogue box. Check the direction of extrusion and 
select New Body as the operation. Click OK to convert the 2D rectangle into a 3D 
rectangular block. 

STEP 5: Start a New Sketch
      Click on Create Sketch from the Solid toolbar to start another sketch. The available 
faces of the rectangular block will appear on the screen. Select the front face of the 
block to create the next sketch. 
<img width="542" height="773" alt="image" src="https://github.com/user-attachments/assets/26d3e1bc-219b-4e3c-a105-80fcc659df2b" />

STEP 6: Select the Front Surface 
        Click on the front surface of the rectangular block. Once the face is highlighted, the 
sketching workspace will open on the selected surface. Check that the correct face is 
selected before proceeding. 

STEP 7: Create a Circle 
        Select Sketch → Circle → Center Diameter Circle. Click on the required centre point 
of the selected face and move the cursor outward to draw the circle. Enter the diameter 
as 100 mm using the dimension input. Press Enter to confirm the value and click Finish 
Sketch after completing the circle. 

STEP 8: Extrude the Circle 
    Select Solid → Create → Extrude and choose the circular profile. Enter the extrusion 
distance as 20 mm in the dialogue box. Check the extrusion direction and select Join if 
the circular feature needs to be combined with the existing rectangular block. Click OK 
to complete the extrusion. 

STEP 9: Start Another Sketch 
      Select Create Sketch from the Solid toolbar to begin another sketch. The available surfaces of 
the 3D model will be displayed. Select the top surface of the rectangular block to continue the 
modelling process. 

STEP 10: Select the Top Surface 
    Click on the top surface of the rectangular block to select it as the sketch plane. Wait until the 
sketching workspace opens and check that the correct surface is selected. The edges of the 
block can be used as references while drawing the required geometry. 

STEP 11: Create Lines 
    Select Sketch → Create → Line from the toolbar. Click on the required starting point and move 
the cursor towards the endpoint to draw the line. Continue drawing the remaining lines 
according to the given isometric drawing. Use horizontal and vertical constraints wherever 
necessary to maintain proper alignment. Enter the required dimensions using the Sketch 
Dimension (D) command. Check the shape and measurements of the sketch, remove unwanted 
portions using the Trim command if needed, and click Finish Sketch. 

STEP 12: Extrude the Remaining Sketch 
          Select Solid → Create → Extrude and click on the required closed sketch profile. Enter the 
extrusion distance as specified in the given drawing. Check the direction and preview of the 
extrusion, select the appropriate operation and click OK to complete the 3D feature. 

STEP 13: Save the Final Model
    After completing all the modelling operations, rotate the model using the ViewCube to observe it 
from different directions. Check the front, top, side and isometric views to ensure that the model 
matches the given drawing. Make any necessary corrections and save the completed model 
using File → Save.
